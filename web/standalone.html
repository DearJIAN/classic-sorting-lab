UNDER THE HOOD

算法伪代码

PSEUDOCODE
01for pass = 0 to n - 2:
02 swapped = false
03 for i = 0 to n - 2 - pass:
04 if a[i] > a[i + 1]:
05 swap(a[i], a[i + 1])
06 swapped = true
07 if !swapped: break

每轮相邻元素两两比较，较大的元素逐渐“冒泡”至数组末端。如果一轮没有交换，数组就已经有序。
